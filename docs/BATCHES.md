# Screening batches

One row per `/screen-apps` batch, added in the batch's last PR, so the funnel can be compared across process changes. Counts only: the ideas themselves stay in the private [idea ledger](APP_ACCEPTANCE.md#the-idea-ledger).

- **Generated:** ideas in the ledger for this batch, as Originator + Idea generator.
- **Researched:** survivors of the screen that were researched (about 3N).
- **Recorded:** candidate PRs opened.
- **Selected / benched / rejected:** the step 6 decisions, counting benched candidates selected from earlier batches under Selected.
- **Promoted:** apps that entered Labs.
- **Live:** apps from this batch that are live now. Update it when one launches or is discarded.
